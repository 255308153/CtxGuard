# 12 · 模式与配置系统 (Configuration & Modes)

## 一、 5 层配置优先级合并机制

CtxGuard 支持从命令行到全局配置的多层级参数覆盖，满足本地开发、CI 测试与生产部署的不同需求：

$$\text{CLI 参数} > \text{环境变量 (CTXGUARD\_*)} > \text{当前工作区 (./ctxguard.yaml)} > \text{全局配置 (~/.ctxguard/ctxguard.yaml)} > \text{系统默认}$$

```text
配置合并流程：
[内置默认 DefaultConfig]
       ↓ 合并
[~/.ctxguard/ctxguard.yaml]
       ↓ 合并
[./ctxguard.yaml]
       ↓ 合并
[环境变量 CTXGUARD_PROXY_PORT 等]
       ↓ 合并
[命令行参数 --port 8787]
       ↓
输出最终强校验后的 AppConfig 实例
```

## 二、 核心配置项结构图解

在 `ctxguard/config/schema.py` 中基于 Pydantic v2 构建了严密的数据模型：

```yaml
# ctxguard.yaml 核心配置摘要
proxy:
  host: "127.0.0.1"
  port: 8787
  timeout_seconds: 120.0

cache_guard:
  enabled: true
  cold_recompact_enabled: true
  cache_ttl_seconds: 300.0          # Anthropic 缓存过期时间 (秒)
  provider_read_discounts:
    anthropic: 0.90                 # 90% 读取折扣
    deepseek: 0.90
    openai: 0.50

dedup:
  enabled: true
  min_chars: 100                    # 超过 100 字符才触发去重
  exclude_patterns: ["*.env*", "*secret*", "*.pem"] # 敏感文件保护

structural_compression:
  json_compressor:
    enabled: true
    min_array_length: 3
  log_cleaner:
    enabled: true
    stacktrace_threshold: 3

adaptive_pipeline:
  level0_threshold: 2000
  level1_threshold: 8000
  level2_threshold: 32000
```
