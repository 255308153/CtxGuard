# 06 · 语义缓存 (Semantic Cache)

## 一、 功能概述

在多轮自动化测试或批量工作流中，Agent 经常会向大模型发起高度相似甚至完全相同的查询（例如对相同代码段进行代码风格审查、相同的系统自检指令）。

`SemanticCache`（`ctxguard/core/semantic_cache.py`）提供两级缓存拦截：
1. **L1 精确哈希缓存（Exact Hash Cache）**：Prompt 的 SHA-256 完全相同时，0 延迟返回历史响应；
2. **L2 语义相似度缓存（Semantic Cosine Cache）**：对于相似度超过阈值（如 `0.96`）的高置信度查询，直接返回复用结果。

---

## 二、 短路收益

- **Token 节省**：输入与输出 Token 均为 0（节省 100%）；
- **响应延迟**：从云端 API 的 1000~3000ms 骤降至本地查询的 **< 1ms**。
