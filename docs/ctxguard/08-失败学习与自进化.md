# 08 · 失败学习与自进化 (Offline Self-Evolution)

> **区别于普通压缩工具的杀手锏**：让 Agent 在每次任务失败与死循环中自动学习，并将修正经验固化落盘。

---

## 一、 它解决的问题

在实际软件研发中，Agent 经常会犯重复的低级错误：
- 连续 5 次执行 `grep` 使用了错误的参数引发报错；
- 陷入文件读写死循环；
- 尝试了多次失败的修复方案后，才在最后一步摸索出正确命令。

如果缺乏自进化机制，当开启新的会话时，**Agent 会把同样的错误再犯一遍**。

---

## 二、 三步离线自进化流水线 (`ctxguard learn`)

```text
本地 SQLite 会话事件日志 (.ctxguard.db)
       │
       ▼
[步骤 1: 死循环与重复报错挖掘 (Loop Detector)]
       │  扫描连续重查相同文件或连续产生相同异常的会话序列
       ▼
[步骤 2: 因果转折点提取 (Causality Extractor)]
       │  定位由 [报错/失败] 转向 [执行成功] 的关键提示与命令动作
       ▼
[步骤 3: 标记块隔离与规则幂等落盘 (Rule Writer)]
       │  生成标准化规则，写入 CLAUDE.local.md / .cursorrules
       ▼
规则生效：后续会话直接由 Agent 读取规则，避免再踩同一个坑
```

---

## 三、 规则落盘格式规范

在 `ctxguard/learn/rule_renderer.py` 中，采用**标记块隔离（Marker Isolation）**，确保多次运行 `ctxguard learn` 具有严格的幂等性：

```markdown
<!-- START_CTXGUARD_LEARNED_RULES -->
## CtxGuard 自动学习到的工程经验 (Updated: 2026-09-15)

- **[Tool Calling]** 执行 `pytest` 时，优先添加 `-v -k` 参数过滤测试用例，避免全量运行导致超时；
- **[Build Error]** 检测到 macOS 环境下缺少 OpenSSL 软链接时，执行 `export LDFLAGS="-L/opt/homebrew/opt/openssl/lib"`；
<!-- END_CTXGUARD_LEARNED_RULES -->
```

- **CLI 命令支持**：
  - `ctxguard learn --dry-run`：仅在控制台预览提取出的因果规则，不修改本地文件；
  - `ctxguard learn`：自动将规则幂等合并写入工作区。
