# 09 · 省钱统计与账本 (Savings Ledger & Telemetry)

## 一、 严密的双向记账模型 (`SavingsLedger`)

为了给用户和企业提供真实可信的成本削减数据，CtxGuard 在本地 SQLite 中记录每一轮请求的完整账目（`ctxguard/storage/savings_ledger.py`）：

```sql
CREATE TABLE IF NOT EXISTS savings_ledger (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    provider TEXT NOT NULL,
    model TEXT NOT NULL,
    original_input_tokens INTEGER NOT NULL,
    optimized_input_tokens INTEGER NOT NULL,
    cache_read_tokens INTEGER NOT NULL DEFAULT 0,
    cache_creation_tokens INTEGER NOT NULL DEFAULT 0,
    output_tokens INTEGER NOT NULL DEFAULT 0,
    saved_tokens INTEGER NOT NULL,
    estimated_cost_raw REAL NOT NULL,
    estimated_cost_actual REAL NOT NULL,
    dollars_saved REAL NOT NULL,
    created_at TEXT NOT NULL
);
```

---

## 二、 核心统计指标与计算口径

1. **Token 压缩率 (Compression Ratio)**：
   $$\text{Ratio} = \frac{\text{optimized\_input\_tokens}}{\text{original\_input\_tokens}}$$
2. **净节省资金 (Dollars Saved)**：
   $$\text{Saved} = \text{Cost}_{\text{Raw}} - \text{Cost}_{\text{Actual}}$$
   其中 $\text{Cost}_{\text{Actual}}$ 严格计算了官方 Prompt Cache 命中所带来的折扣。

---

## 三、 多端可视化与 CLI 支持

- **CLI 命令行查看**：
  - `ctxguard stats`：查看当前工作区总体 Token 消耗与节省统计；
  - `ctxguard savings`：生成 ASCII 表格或 JSON 格式的资金节省看板；
- **内置 Web Dashboard**：
  - 访问 `http://127.0.0.1:8787/dashboard` 查看实时请求吞吐、延迟分布与累计节省趋势图。
